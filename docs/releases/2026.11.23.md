## English

First public release, with Chinese and English documentation, standard Docker Compose, a QNAP independent-IP template and an offline image.

- Target gateways: RB5009UG+S+IN and RB5009UPr+S+IN. Hardware-validated on UPr with RouterOS 7.25.1 and API 8728; separate UG hardware validation is pending. Other models are untested.
- Image platform: Linux amd64 (Intel / AMD x86_64). Run on a NAS / Docker host and connect to the gateway. The UI is Chinese.
- Collection is unchanged: status 3 s, traffic 5 s, clients 10 s, quality 60 s. Includes gzip and incremental history transfer.
- This release prepares documentation, templates, MIT licensing and image metadata; it does not change collection logic.

GitHub Container Registry: `ghcr.io/haoranxu1989/network-rb5009:2026.11.23`

For offline installation, download the tar and `SHA256SUMS`, verify the checksum and run the command above. QNAP can import the same tar in Container Station. Replace example addresses, credentials and the QNAP network name. Preserve your existing `/data` mount when upgrading.
